# 上下文压缩·遗留项 3：decompress/search_context 断点索引回读原文容器（含 tier 嵌套还原打通）

> **状态：已完成（2026-09-13，续 112）**。实现见 [acp-context/src/index.ts](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/plugins/acp-context/src/index.ts)。相比设计，`decompress`/`search_context` 的 `startId/endId` 未走 `blockRefToMessageId(startRef→idBase)`，改用 `blockSpan`/`coveredSpan`（基于实际还原出的原文/状态+归档轻量计算），更能反映真实覆盖范围——与宿主 `resolveAcpBlockOriginals` 的容器切片基于消息 id 对齐。`restoreBlockMessages` 递归、`runPreModel` 折叠轮持久化原文均已落地；acp-context 21 用例全绿、单包 typecheck 通过。

## Context（问题定位）

ACP 插件当前有**两条并存的原文还原路径**，未完全打通：

1. **插件内路径**：`decompress` 用 `restoreBlockMessages`（[acp-context/src/index.ts:762](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/plugins/acp-context/src/index.ts#L762-L793)）从 `ctx.archive` 还原。`ctx.archive = 本轮历史原文(byId) + meta[ACP_ARCHIVE_KEY]`（[index.ts:482-494](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/plugins/acp-context/src/index.ts#L482-L494)）。
2. **宿主统一 loader 路径**：CLI `loadFullHistory` / `resolveAcpBlockOriginals`（[cli/index.ts:1603](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/cli/src/index.ts#L1603-L1612)）按 session.blocks（断点索引 startId/endId）从 `meta[ACP_ARCHIVE_KEY]` 切片。

勘察确认的**两个真实缺口**：

- **缺口 A（跨重启原文丢失）**：`ACP_ARCHIVE_KEY` 目前只在 `runCompacting`（session.compacting 折叠）时写入（[index.ts:692-704](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/plugins/acp-context/src/index.ts#L692-L704)）。`runPreModel` **每轮 processTurn 折叠**只持久化 `ACP_META_KEY`，折叠窗口原文依赖 `session.messages` 存活。一旦该窗口随后被 **generic session compact** 物理裁剪（runPreModel 折叠块不进 session.blocks → core 判定 windowHandled=false → 原文只进 `.cmp.orig`），跨重启后 `ctx.archive`（仅 ACP archive 水合）**不含该原文** → `decompress` 还原失败。
- **缺口 B（tier2/3 嵌套还原未验证）**：`restoreBlockMessages` 只展开 `effectiveMessageIds + directMessageIds`，**未递归 `directBlockIds`**（kernel 块字段见 [types.d.ts:27-29](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/plugins/acp-context/node_modules/acp-kernel/dist/types.d.ts#L27-L29)）。若 kernel 的 `effectiveMessageIds` 不含嵌套子块覆盖的原始消息，tier2/3 父块还原会缺内层原文——需递归 + 去重兜底，并补嵌套用例验证。

**目标**：`decompress`/`search_context` 走"断点索引回读统一原文容器"（meta[ACP_ARCHIVE_KEY]），保证跨重启 + tier 嵌套下还原完整；新增断点索引输出字段，与统一块模型/宿主 loader 对齐。

## 设计决策

| # | 决策 | 理由 |
|---|------|------|
| D1 | `runPreModel` 折叠时把**新增折叠块覆盖的原文**合并持久化到 `ACP_ARCHIVE_KEY` | 在 generic compact 裁剪前由 ACP 自行保全原文（缺口 A），decompress 跨重启仍可还原；仅折叠轮写、合并 prev，不做每轮全量 IO |
| D2 | `restoreBlockMessages` 按 `directBlockIds` 递归子块 + `effective/direct` 消息 id 去重收集 | 双保险覆盖嵌套（缺口 B）：effective 已含嵌套则冗余无害，不含则递归补齐 |
| D3 | `decompress` 输出与 `search_context` 结果增加断点索引 `startId/endId`（kernel `startRef/endRef` → byRef → coreId → harness 消息 id） | 与统一块模型断点索引对齐，宿主可据此定位/去重；映射失败省略字段（增量，不破坏现有字段） |
| D4 | 仅改 acp-context 插件 + 测试；不动 cli/core/session | 宿主 loader 已按 startId/endId 工作，本项补的是"ACP 侧把原文与索引放进统一容器" |

## 逐文件改动

### 1. packages/plugins/acp-context/src/index.ts

- **`restoreBlockMessages` 嵌套递归**：
  - 新增模块级辅助 `collectCoveredIds(state: CompressionState, block: CompressionBlock, out: Set<string>): void`：
    - `for (const id of block.effectiveMessageIds) out.add(id)`；`for (const id of block.directMessageIds) out.add(id)`
    - `for (const childId of block.directBlockIds)`：`const child = state.blocks.find(b => b.blockId === childId)` → 递归（防环用 `out` 自身即天然去重）
  - `restoreBlockMessages` 改用 `collectCoveredIds` 得到的集合，保留现有"archive.get → byRef 兜底"逻辑（[index.ts:774-782](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/plugins/acp-context/src/index.ts#L774-L782)），遍历顺序用 Set 插入序（effective 在前、子块递归在其后）。
- **`runPreModel` 折叠原文持久化**：
  - `processTurn` 前快照：`const prevBlockIds = new Set(ctx.state.blocks.map((b) => b.blockId))`（插在 [index.ts:496](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/plugins/acp-context/src/index.ts#L496) processTurn 之前）。
  - `processTurn` 后（现有 ACP_META_KEY 持久化块之后）：`const newBlocks = res.state.blocks.filter((b) => !prevBlockIds.has(b.blockId))`；若 `newBlocks.length > 0`：读 prev `ACP_ARCHIVE_KEY` 合并，遍历 `newBlocks` 的 `collectCoveredIds` 结果，`inflat.byId.get(coreId)` 取原文写入 `archiveObj[coreId]`，`await meta.patch({ [ACP_ARCHIVE_KEY]: archiveObj })`（复用 runCompacting 同款合并写模式 [index.ts:694-704](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/plugins/acp-context/src/index.ts#L694-L704)）。
- **`decompress` 工具**（[index.ts:272-294](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/plugins/acp-context/src/index.ts#L272-L294)）：`DecompressOutput` 增加 `startId?: string; endId?: string`；从 `block.startRef/endRef` → `sctx.state.messageRefs.byRef[ref]` → coreId → `idBase(coreId)`（[adapter.ts:71](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/plugins/acp-context/src/adapter.ts#L71-L74)）得到 harness 消息 id；映射失败省略。
- **`search_context` 工具**（[index.ts:298-321](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/plugins/acp-context/src/index.ts#L298-L321)）：`SearchResult` 增加 `startId?: string; endId?: string`，同上映射。
- 新增模块级 `blockRefToMessageId(state, ref): string | undefined` 辅助（byRef → idBase），decompress/search 共用。
