# 上下文压缩·阶段四：前端按需渲染

> 目标：TUI 打开超长会话不再一次性渲染全量历史——压缩过的会话把 `session.blocks` 渲染为**提示行**（不渲染内容，符合"只提示自动压缩过"的诉求），点击可经 loader 惰性展开原文；未压缩但超长的近期段用"最近 N 条 + 更早省略提示 + 点击加载更多"控制首屏；`/history` 等语义经 `loadFullHistory` 透传保留。

## 背景与现状（勘察结论）

- TUI 历史入口只有一处：`setSession(s)` → `setState(messagesToBlocks(s.messages))`（[tui.tsx:929](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/cli/src/tui.tsx#L929-L932)），一次性全量转换；`messagesToBlocks`（[tui.tsx:526](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/cli/src/tui.tsx#L526-L536)）不识别 `blocks`。
- `ChatBlockKind = system|user|thinking|assistant|tool`（[tui.tsx:127](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/cli/src/tui.tsx#L127)），`renderBlockBody` 无压缩块分支。
- `/resume` 与 boot 已回填 `next.blocks` + 注册 `setHistoryLoader`（[cli/index.ts:1834](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/cli/src/index.ts#L1834-L1840)），`setSession` 收到的 Session 自带 `blocks`。
- `loadFullHistory(sessionId, range?)` 已支持 startId/endId 过滤，但 `filterByRange` 对 `blockIds` 是"忽略兜底"（[cli/index.ts:1443](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/cli/src/index.ts#L1443-L1446)），需要补真正的 blockIds 分支。
- opentui ScrollBox 有 `viewportCulling` 绘制裁剪，渲染瓶颈在 ChatBlock 数组构建与 vnode 创建，不在终端绘制——因此选"顶部省略 + 点击加载"而非虚拟滚动。

## 设计决策

| # | 决策 | 理由 |
|---|------|------|
| D1 | 压缩块渲染为 `'compact'` 提示块（仅一行摘要元信息：来源/主题/条数，不渲染 summary 全文） | 贴合"只提示自动压缩过"；块多时首屏也不膨胀 |
| D2 | 超长近期段分页：`HISTORY_PAGE = 100`，只渲染最近页 + `'loadmore'` 提示块 | 未压缩超长会话首屏可控；加载更多纯内存切片（messages 在内存） |
| D3 | 展开压缩块走 loader：`loadHistory(sessionId, { blockIds: [id] })` → 原文插入提示块位置 | 复用统一块模型原文回溯，跨重启/ACP 双源都生效 |
| D4 | 展开/加载更多为**纯函数**（输入 state + 参数 → 新 state），便于单测 | 与现有模块 B 纯函数风格一致 |
| D5 | `TuiReplOptions` 增加可选 `loadHistory`，cli `startTuiRepl` 注入 `app.loadFullHistory` 包装 | 不破坏现有调用方（可选字段） |

## 逐文件改动

### 1. packages/cli/src/tui.tsx

- `ChatBlockKind` 增加 `'compact' | 'loadmore'`。
- `ChatBlock` 增加可选：`msgId?: string`（关联原始消息，防重复）、`blockId?: string`（压缩块 id，展开用）、`loading?: boolean`。
- 新增常量 `HISTORY_PAGE = 100`。
- `messagesToBlocks(messages, blocks?, page = HISTORY_PAGE)`（向后兼容，默认同现状）：
  - `blocks` 按 `at` 升序渲染为 `compact` 块，插在最前；每行形如 `📦 已自动压缩历史 · [topic] · 来源(source) · N 条消息`，`blockId` 关联；`blocks` 为空不产生任何块（回归零变化）。
  - `messages.length > page` 时只取末尾 `page` 条，最前插入 `loadmore` 块：`▲ 更早 X 条消息已省略（点击加载更多）`。
- 新增纯函数 `expandCompactBlocks(state, blocks: ChatBlock[], originals: Message[]): ChatState`：
  - 找到 `blockId` 匹配的 `compact` 块，把该块替换为 `originals` 转出的普通消息块（`roleToKind`/`messageText` 复用），新 id 从 `nextId` 起递增；返回新 state。
- 新增纯函数 `loadOlderBlocks(state, older: Message[], page = HISTORY_PAGE): ChatState`：
  - 在 `loadmore` 块位置之后插入 `older` 转出的消息块；若 `older` 已覆盖全部隐藏消息则移除 `loadmore` 块。
- `renderBlockBody` 增加 `case 'compact'`（dim 提示行，`onMouseUp` → 展开回调，loading 时显示 `⏳ 加载中…`）与 `case 'loadmore'`（dim 提示行，`onMouseUp` → 加载更多）。渲染回调经 TuiApp 内的 `options.loadHistory` 接入。
- `TuiReplOptions` 增加 `loadHistory?: (sessionId: string, range?: HistoryLoadRange) => Promise<Message[]>`（`HistoryLoadRange` 从 `@harness/session` 导入 type）。
- `TuiApp.setSession`：`setState(messagesToBlocks(s.messages, s.blocks))`；新增展开/加载更多 handler，内部调 `options.loadHistory`（缺失则静默不展开）。

### 2. packages/cli/src/index.ts

- `loadFullHistory` 增加 `range.blockIds` 分支：`blockIds` 存在时，只对命中块逐个 `resolveBlock` 取原文并拼接返回（不做全量 reconstruct + filter），保证按块惰性加载语义。
- `startTuiRepl` 调用处（[index.ts:2521](file:///Users/oyoungy/Documents/project/XiaoZhi-new/packages/cli/src/index.ts#L2521)）注入 `loadHistory: (sid, range) => app.loadFullHistory(sid, range)`。

### 3. packages/cli/src/tui.test.tsx

- `messagesToBlocks`：带 blocks → 首部 compact 块（含 blockId/source/条数）；无 blocks 零变化；超长 messages 分页 + loadmore 块。
- `expandCompactBlocks`：命中块替换为原文块、nextId 递增、未命中不变。
- `loadOlderBlocks`：插入更早页、覆盖全部后移除 loadmore。
- TuiApp 集成：mock `loadHistory`，点击 compact 块后原文消息上屏。

### 4. packages/cli/src/cli.test.ts（若现有 loadFullHistory 用例覆盖 range 则追加 blockIds 用例）

- `loadFullHistory(sessionId, { blockIds: [...] })` 只返回命中块原文。

## 风险与对策

| 风险 | 对策 |
|------|------|
| `filterByRange` 曾忽略 blockIds，依赖该语义的调用方可能受影响 | 新增分支是纯增量：无 `range.blockIds` 时行为与现状完全一致 |
| compact 块展开的原文较大 | 每块原文本就是"一个折叠窗口"（有界），一次展开一页可接受；/history 兜底全量 |
| `loadmore` 与 `compact` 都出现在首部，视觉混淆 | 文本措辞区分（📦 压缩历史 vs ▲ 更早省略），dim 样式一致但图标不同 |
