派一个子 Agent 执行独立任务（隔离 session）。输入：agentId（子 Agent ID）、prompt（任务描述，必须自包含：目标 + 相关路径 + 已知结论/约束 + 验收标准 + 范围边界）、description（3-5 词简短描述，可选）、model（模型覆盖，可选）、sessionId（续接已有子 session，可选）、runInBackground（可选）、maxSteps（可选，>=1 或 -1）。决策规则：需要结果才能继续 → 前台（默认）；有独立工作可并行、或无需阻塞当前流程 → runInBackground: true（后台异步执行，立即返回 taskId）。后台任务完成后系统自动向本会话注入任务完成通知，不要 sleep/poll/主动查询进度。派工前先评估复杂度：每个子 Agent 是一份独立上下文、开销随路数线性增长 —— 默认 2-3 路、最多 4 路，且各路范围必须两两互斥（写明文件集，公共文件只让一路读）；能自己做或能合并的就不要派。
