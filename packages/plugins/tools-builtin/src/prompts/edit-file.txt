编辑文件：精确查找并替换文本片段（参考 Claude Code 的 edit 工具）。

对文件执行精确字符串替换。

用法：
- 编辑文件前**必须先在本会话中用 read_file 至少读取过一次**该文件（先读，再编辑）
- 只替换第一个匹配（默认）；整个文件所有匹配用 replaceAll=true
- old_string 必须唯一：若在文件中出现多处（≥2）会失败并提示，请提供更大、更独特的上下文，或用 replaceAll 替换全部实例
- 保留 read 输出中精确的缩进（tab/空格），不要把行号前缀带进 old_string/new_string
- 换行会自动归一：文件是 CRLF 时，你传入的 \n 也会按 CRLF 匹配（无需手动处理换行符）
- 引号智能匹配：若精确匹配失败，文件里的花引号（“ ” ‘ ’）可按直引号（" '）匹配，无需精确复制引号
- 删除行（new_string 为空）时会顺带删掉该行尾随换行，不会留下空行
- 优先编辑既有文件，不要新建文件；避免 emoji
- 只用本工具做查找替换（不是 sed/awk），只允许在工作目录内操作
