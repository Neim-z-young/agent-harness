读取文件内容（参考 Claude Code 的 read 工具）。

从本地文件系统读取文件。可以直接访问任何工作目录内的文件。

用法：
- file_path 必须是绝对路径（或相对 cwd 的相对路径）
- 默认从文件开头读取，最多 256KB / 10000 行；大文件优先读取目标部分
- 可通过 offset（起始行号，1-based）+ limit（行数）读取指定范围
- showLineNumbers=true 时返回带行号前缀（cat -n 格式）的内容
- 读取文件用本工具（不是 cat / head / tail / sed），只读文件不读目录
- 若文件不存在或超出工作目录，会返回错误
