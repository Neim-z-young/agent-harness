写入文件（参考 Claude Code 的 write 工具）。

写入或创建本地文件。

用法：
- 若文件已存在且用默认 overwrite 模式 → 会覆盖原内容；写入既有文件前**必须先用 read_file 读取**（本工具不会自动确认你是否已读）
- 优先用 edit_file 修改既有文件（只发送改动），本工具用于创建新文件或整篇重写
- 不要在没有用户明确要求时主动创建文档（*.md）或 README 文件
- mode：overwrite（覆盖/创建，默认）/ append（追加）/ create（仅新建，已存在则报错）
- 只允许在工作目录内写入
- 除非用户明确要求，否则避免写入 emoji；不要在文件里写 emoji
