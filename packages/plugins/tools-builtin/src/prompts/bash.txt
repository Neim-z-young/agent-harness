执行 shell 命令（沙箱受限，参考 Claude Code 的 bash 工具）。

执行命令并返回输出。工作目录在命令间保持，但 shell 状态不保留。

用法：
- 文件/内容搜索用专用工具（read_file 读文件、grep_file 搜索、glob 查找文件），不要用 find/grep/cat/head/tail/sed/awk/echo 来代替
- 命令在沙箱中执行：危险命令会被硬性拒绝（如 rm -rf /、fork bomb、写裸盘、关机重启、curl|bash），cwd 被限制在工作目录内，敏感环境变量（API key/密钥）会被隔离
- 命令成功执行即返回 ok，命令状态看 exitCode（0=成功，非0=失败）；spawn 失败或中断才算工具失败
- 多条独立命令可一次多条并行；有依赖的用 && 串接；用 ; 表示不在乎失败顺序执行；命令不要用换行分隔
- 需要权限的命令会向用户确认
- 环境变量可通过 env 传入
